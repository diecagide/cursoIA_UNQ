Bloque B — Modelos y plataformas

Nano Banana ↗

Google DeepMind

Características▾

Nombre propio del modelo

"Nano Banana" es el apodo con el que se popularizó esta familia de modelos de imagen de Google. Hoy conviven dos versiones: Nano Banana Pro (Gemini 3 Pro Image) y Nano Banana 2 (Gemini 3.1 Flash Image)

Se usa para

Pro prioriza la calidad y el detalle máximo —composiciones complejas, texto legible dentro de la imagen—; 2 prioriza la velocidad y el costo, con buen seguimiento de instrucciones. No es que una sea "mejor" que la otra: son dos niveles pensados para necesidades distintas

Dónde funciona

Gemini (app y web), Google AI Studio, Vertex AI, y Pro además como modelo dentro de Adobe Firefly

GPT

GPT Image 2 ↗

OpenAI

Características▾

Nombre propio del modelo

GPT Image 2 — en septiembre de 2026 OpenAI sumó una actualización, GPT Image 2.5, que hoy es la versión que usa ChatGPT por defecto

Se usa para

Prompts largos y detallados (incorpora un paso de razonamiento previo a la generación) y buen renderizado de texto dentro de la imagen

Dónde funciona

ChatGPT (tocando el ícono "+" y eligiendo "Crear imagen"), y la API de OpenAI

MJ

Midjourney ↗

Midjourney, Inc.

Características▾

Nombre propio del modelo

No tiene un nombre separado del producto: se lo conoce por su número de versión (hoy V8.2), más una línea aparte especializada en anime (Niji)

Se usa para

Estética artística e ilustrativa muy reconocible, arte conceptual, piezas con una identidad visual propia

Dónde funciona

Sitio web propio (midjourney.com, desde 2024) y también por Discord, donde nació

Flux.2 ↗

Black Forest Labs

Características▾

Nombre propio del modelo

FLUX.2, con varias variantes: [dev] y la familia [klein] (más liviana, pensada para correr en una computadora con menos recursos) son de código abierto; pro, flex y max son versiones privadas más potentes, disponibles solo por API

Se usa para

Fotorrealismo, textura, manejo de luz natural

Dónde funciona

Plataforma propia (bfl.ai), y también integrado dentro de otras plataformas como Adobe Firefly

Adobe Firefly ↗

Adobe

Características▾

Nombre propio del modelo

Firefly Image Model 4 y 4 Ultra (modelos propios) — la plataforma además da acceso a modelos de otras empresas

Se usa para

Integrarse al flujo de trabajo de Photoshop, Illustrator y Premiere, con licencia pensada para uso comercial

Dónde funciona

firefly.adobe.com, y dentro de las apps de Adobe

Rw

Runway Gen-4 Image ↗

Runway AI

Características▾

Nombre propio del modelo

Gen-4 Image. Runway es conocida sobre todo como empresa de generación de video (su modelo de video más reciente es Gen-4.5); el modelo de imagen es un producto complementario, pensado para generar y mantener referencias visuales consistentes que después se pueden animar

Se usa para

Mantener un mismo personaje, objeto o lugar de forma consistente entre varias imágenes distintas, a partir de fotos de referencia. Es un patrón habitual en las empresas de video: Kuaishou, por ejemplo, además de su modelo de video Kling, tiene un modelo de imagen propio, Kolors

Dónde funciona

Plataforma propia (runwayml.com) y vía API
