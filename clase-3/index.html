Bloque B — Modelos y plataformas

NB

Nano Banana Pro ↗

Google DeepMind

Características▾

Nombre propio del modelo

Gemini 3 Pro Image

Se usa para

Composiciones complejas, texto legible dentro de la imagen, la máxima calidad y fidelidad posible

Dónde funciona

Gemini (app y web), Google AI Studio, Vertex AI, y como modelo dentro de Adobe Firefly

NB2

Nano Banana 2 ↗

Google DeepMind

Características▾

Nombre propio del modelo

Gemini 3.1 Flash Image

Se usa para

Generación rápida y económica, con buen seguimiento de instrucciones — no es "mejor" que Nano Banana Pro, es un nivel distinto pensado para velocidad en vez de calidad máxima

Dónde funciona

Gemini (app y web), Google AI Studio, Vertex AI

GPT

GPT Image 2 ↗

OpenAI

Características▾

Nombre propio del modelo

GPT Image 2

Se usa para

Prompts largos y detallados (incorpora un paso de razonamiento previo a la generación) y buen renderizado de texto dentro de la imagen

Dónde funciona

ChatGPT (tocando el ícono "+" y eligiendo Imagen), Sora, y la API de OpenAI

MJ

Midjourney ↗

Midjourney, Inc.

Características▾

Nombre propio del modelo

No tiene un nombre separado del producto: se lo conoce por su número de versión (hoy V8.2), más una línea aparte especializada en anime (Niji)

Se usa para

Estética artística e ilustrativa muy reconocible, arte conceptual, piezas con una identidad visual propia

Dónde funciona

Sitio web propio (midjourney.com, desde 2024) y también por Discord, donde nació

Flux.2 ↗

Black Forest Labs

Características▾

Nombre propio del modelo

FLUX.2, con variantes: [dev] de código abierto, y versiones privadas más potentes (Pro/Max)

Se usa para

Fotorrealismo, textura, manejo de luz natural

Dónde funciona

Plataforma propia (bfl.ai), y también integrado dentro de otras plataformas como Adobe Firefly

Ff

Adobe Firefly ↗

Adobe

Características▾

Nombre propio del modelo

Firefly Image Model 4 y 4 Ultra (modelos propios) — la plataforma además da acceso a modelos de otras empresas

Se usa para

Integrarse al flujo de trabajo de Photoshop, Illustrator y Premiere, con licencia pensada para uso comercial

Dónde funciona

firefly.adobe.com, y dentro de las apps de Adobe

Rc

Recraft ↗

Recraft

Características▾

Se usa para

Piezas de diseño gráfico, con buen manejo de tipografía y de identidad de marca

Dónde funciona

Plataforma propia (recraft.ai)

Rw

Runway Gen-4 Image ↗

Runway AI

Características▾

Se usa para

Mantener un mismo personaje, objeto o lugar de forma consistente entre varias imágenes distintas, a partir de fotos de referencia

Dónde funciona

Plataforma propia (runwayml.com) y vía API
